拡張⽅針サマリー

き含む）で⽂書化する。
3. どこでも呼べる⼊⼝：共有シート、テキスト選択メニュー、ウィジェット、クイック設定
タイル、 Android 16 の AppFunctions で OS やエージェントから直接呼ばせる。
4. ゼロダウンロード起動： Gemini Nano 搭載端末では端末内蔵モデルで即利⽤、未対応端末
やより⾼品質が必要な場⾯は llama.cpp へ切替えるハイブリッドランタイム。

## p.4

AppFunctions は実験的プレビューの段階なので、 v1.5 で実装し、 API 変更に備えて Kotlin
側の薄い層に閉じ込める。
E. ゼロダウンロード起動（ハイブリッドランタイム）
初回起動で端末を診断し、 Gemini Nano （ AICore 経由）が使える端末では即チャット‧
要約を開始。モデルダウンロード画⾯を出さない。
Nano では⾜りない⽤途（⻑い RAG ⽂脈、独⾃モデル、 LoRA ）は llama.cpp の GGUF モデ
ルに切替え、「より⾼品質なモデルを⼊れる」を後から提案する。
ルーターは⽤途ごとに経路を決める：短い要約‧⾔い換え →Nano 、⽂書 RAG→GGUF 、
⽂字起こし →whisper.cpp 。
注意： Nano の対応端末と API は段階的に変わり、ブートローダー解除端末では使えない。
必ず GGUF へ縮退できること。
F. 出⼒テンプレート
議事録、⽇報、週報、⽐較表、 FAQ 、暗記カード、メール下書きを組み込みテンプレート
として提供。
構造化出⼒（ JSON スキーマ指定）で⽣成し、 Markdown ‧ CSV ‧ Anki （ .apkg ）‧ ICS
（ ToDo を予定に）へ書き出す。
ユーザー⾃作テンプレートをファイルで共有できる（プロンプトのみ、実⾏コードは含ま
ない）。
G. ⽇本語に強い検索（ハイブリッド検索）
ベクトル検索だけでは型番、⼈名、条⽂番号が外れやすい。 Rust 製形態素解析 Lindera に
よる全⽂検索（ BM25 ）とベクトル検索を組み合わせ、 RRF で統合する。
表記ゆれ（全⾓半⾓、旧字体、カタカナ⻑⾳）を正規化する。
回答前に根拠スコアを判定し、閾値未満なら「資料には⾒つかりません」と答える（無理
に答えないモード）。
H. 学習モード
資料から確認問題‧暗記カードを⽣成し、間隔反復（ SRS ）で出題する。
誤答した問題は元資料のページへジャンプして復習できる。
学⽣ペルソナ向けの Pro 機能の柱にする。
I. オフライン翻訳‧会話通訳
⽂書翻訳（原⽂と訳⽂の対訳表⽰）、カメラ翻訳（看板‧メニュー）、 2 ⼈⽤の対⾯通訳モ
ード（画⾯を上下分割）。

Rust core を共有したデスクトップ版（ Windows/macOS/Linux ）を⽤意し、 LAN 内でワ
ークスペースを E2E 暗号化同期する。
PC をオフロード先として使い、スマホから PC の⼤きいモデルに質問できる（ベース設計
の PC offload を製品化）。
M. 機密モード‧法⼈向け
ワークスペース単位の⽣体認証ロック、画⾯キャプチャ禁⽌（ FLAG_SECURE ）、最近使
ったアプリ画⾯でのぼかし。
Android Enterprise の managed configurations で、ネットワーク利⽤禁⽌、
AppFunctions 公開禁⽌、許可モデル⼀覧を管理者が配布できる。
監査ログ（誰がいつどの⽂書に質問したか）を端末内に保持し、書き出せる。
N. アクセシビリティ
回答の読み上げ（ローカル TTS ）、ふりがな付与、「やさしい⽇本語」への⾔い換え、⽂字
サイズ連動。
⾼齢者や⽇本語学習者にも届き、機能単体でもストア検索流⼊を⾒込める。
アーキテクチャ拡張
基本構成（ Compose → UniFFI → Rust core → llama.cpp ）は変えず、 Rust core に 6 モジュー
ル、ランタイムに whisper.cpp ‧ OCR ‧ Gemini Nano を⾜します。
