# LocalMind v2 ロードマップ

出典: `LocalMind 拡張設計書 v2.pdf`（2026-11-04）。工数は「経験ある Android/Rust 開発者1人」基準の相対値で、確定納期ではない。

## 方針
「資料に答えるチャット」から「スマホのどこからでも呼べる、記録と資料のローカル秘書」へ。
画像生成・キャラクターチャット・常駐型エージェントは対象外。

## ゲート
各ゲート未達なら次フェーズに進まず前フェーズの品質改善を優先する。

| ゲート | 通過条件 |
|---|---|
| G1（MVP→v1.5） | 初回価値到達 ≤5分（Nano端末 ≤1分）／Nano 不可でも GGUF に縮退して動作／6GB 端末で動作／ハイブリッド検索で型番・人名・条文番号が取れる／根拠不足時に「見つかりません」と答える |
| G2（v1.5→v2） | 録音中クラッシュ後に直前の30秒チャンクまで復元／録音中は録音・VAD のみ（重い処理が同時に走らない）／Foreground Service の Play 審査要件を満たす／OCR 信頼度表示と修正 UI がある |
| G3（v2→v2.5） | AppFunctions が要約と出典のみ返し全呼び出しが記録される／機密ワークスペースが常に非公開／週あたり取り込み数・引用タップ率・「見つかりません」率が計測できる（端末内集計） |

## 依存順序
フェーズ0 → scheduler / router → E・G・C → A・B・F → D・K → H・I・N → J・L・M
- A が F（議事録テンプレート）と D（createMeetingNote）の前提。
- G（search）が H・J・K の前提。
- L（sync）が M の一部（PC オフロード）と独立。
