# リスクと未決事項

## リスク

| リスク | 影響 | 対策 |
|---|---|---|
| 録音中に LLM・OCR が同時に走りメモリ不足 | 録音停止（最悪データ損失） | 録音中は録音・VAD のみ。重い処理は停止後か充電中に順番実行（scheduler で強制） |
| 長時間文字起こしの発熱・電池消費 | 端末が熱くなり評価低下 | 2段構成（仮→充電中に高精度）、Thermal mode 連動、処理時間の事前見積もり表示 |
| Gemini Nano / AppFunctions の API 変更 | 仕様変更 | Kotlin 側の薄いアダプター層に隔離、常に GGUF へ縮退 |
| AppFunctions 経由の情報流出 | 機密が他エージェントに渡る | 要約と出典のみ返す、ワークスペース単位の公開設定、機密は常に非公開、全呼び出しを記録 |
| 録音の同意・法的問題 | 無断録音トラブル | 開始時の同意確認、録音中の常時通知、録音ファイルの自動削除期限 |
| OCR 精度（縦書き・手書き） | 検索の信頼低下 | 信頼度表示、元画像と並べて確認・修正できる UI |
| 機能過多で UX が散漫 | 「何のアプリか」が伝わらない | ホームは取り込み＋今日の ToDo に絞り、翻訳・学習はワークスペース内から呼ぶ |
| Foreground Service のポリシー | Play 審査で却下 | microphone タイプを録音中のみ使用、用途を Play Console で申告 |

## 未決事項（ベータの利用データで決定）
1. 無料版の録音上限（具体的な時間は未定）
2. 話者自動分離を v2 に入れるか（v1 は手動で話者A/Bを命名、自動は実験機能）
3. PC コンパニオンを OSS にするか

価格も未定（プラン構成のみ設計書に記載）。

## KPI（端末内集計、送信はオプトインのみ・デフォルト OFF）
- 初回価値到達時間（目標 ≤5分、Nano 端末 ≤1分）
- 週あたり取り込み数
- 引用タップ率
- 「見つかりません」率（高すぎ＝検索品質、低すぎ＝幻覚の疑い）
- 議事録書き出し率（Pro 転換の先行指標）

送信する場合は集計値のみ、内容は Privacy Inspector にそのまま表示する。
